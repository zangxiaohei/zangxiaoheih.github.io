客户一留言，微信立刻响

不用装 App、不用开自启动、不用等手机后台。

原理：客户在网站提交留言或发客服消息，数据库那一秒就直接发到你微信「服务通知」，有声音、有横幅。微信本来就常驻，所以是秒到。

配置一次，以后永久生效。

第 1 步：拿一个推送 token（2 分钟）

  1. 点下面的按钮，用你的微信扫码登录 PushPlus（免费，每天 200 条，够用）
  2. 登录后点右上角头像 → 一对一推送（或「密钥管理」）
  3. 复制那串 token（一长串字母数字）
  4. 微信公众号会自动让你关注「pushplus 推送加」——必须关注，消息就是从这里来的
打开 PushPlus 扫码登录 →

报错了怎么办

  1. 粘贴前先 Ctrl+A 全选，把编辑器里残留的旧内容删干净再粘
  2. 粘完看一眼最后一行是不是 where id = 1;，不是就说明没粘全，回上一步重新点「生成并复制」
  3. 报错信息里如果带 LINE 数字，把那个数字告我，我按行定位
  4. 这段 SQL 可以重复执行，不碰客户数据，跑错了改好再跑一遍就行

第 5 步：验货

  1. 用另一台手机（或者让别人）在官网提交一条留言
  2. 1～2 秒内，你微信应该弹出「新客户留言 · 张三」
  3. 在线客服里发一条消息，也会立刻收到「在线客服新消息」
如果没收到：先在 PushPlus 网站里点「发送消息」给自己发一条。那条能收到，说明 token 和关注都正常，问题在 SQL；那条也收不到，说明公众号没关注。
