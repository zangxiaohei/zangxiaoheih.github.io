把后台真正「安装」到手机桌面

  1. 请确认用 Chrome 浏览器打开本页（微信 / QQ 内打开没法安装）。
  2. 点下面的绿色大按钮 「📲 安装到桌面」，屏幕底部会弹出系统确认框，点 「安装」。
  3. 如果按钮没反应：点 Chrome 右上角「⋮」菜单 → 找 「安装应用」（有的手机显示为「添加到主屏幕」）→ 点「安装」。
  4. 安装成功后，手机桌面会出现绿色盾牌图标「中天后台」——以后都从这个图标打开后台，才有红点提醒。

⚠️ 注意：浏览器菜单里的「下载网页」只是存一个文件（.mht），不是安装，桌面上不会出现图标，也没有红点。下载列表里的 .mht 文件可以删掉。

小提示：安装弹窗被点过「取消」后，Chrome 会在一段时间内不再弹出，这时请直接用菜单「⋮ → 安装应用」。
