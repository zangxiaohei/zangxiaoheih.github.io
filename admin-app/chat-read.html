开通「已读 / 未读」

只在第一次做一次，之后聊天自带已读状态。

开通后两头都能看见：

你回复客户一条消息好的，明天送● 未读
客户打开聊天窗看过好的，明天送✓ 已读

后台会话列表里，每个客户名字后面会直接显示 未读条数（红色小数字），打开会话自动清零。

只有建一个查询函数，不删数据、不改表结构。全篇没有 $ 符号、没有变量声明，复制粘贴不会掉字符。

第 2 步：到 Supabase 执行一次

  1. 点下面按钮打开 SQL 编辑器
  2. 先 Ctrl+A 全选删掉里面的旧内容，再粘贴、点 Run
  3. 成功标志：结果里出现一行 已读状态函数已就位 = true
打开 Supabase SQL 编辑器 →

第 3 步：验一次

  1. 用手机打开网站 → 右下角聊天窗 → 发一句话
  2. 消息下面应该先显示灰色 已送达
  3. 到后台点开这个会话（什么都不用回）
  4. 手机上看 → 那条消息变成绿色 已读
后台侧：你回复客户后，气泡下面会显示「● 未读」，客户看到后自动变「✓ 已读」，大约 6 秒内更新。

几点说明

  1. 没开通也不影响用：一直显示「已送达」，不会报错、不会卡住
  2. 「已读」的判定是「客户真的打开了聊天窗」，页面在后台挂着不算
  3. 只会返回两个数字（读到第几条、还有几条没读），匿名访客看不到任何聊天内容
  4. 你可以主动清零：后台顶部「全部已读」把留言和客服未读一起清掉
