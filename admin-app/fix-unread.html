修复安卓角标（只差这一步）

手机上的开关已经全开对了。现在的问题是：App 用匿名身份读不到「在线客服」的未读条数，它以为 0 条，所以不发角标通知。

给数据库加一个统计函数就好了，不用重装 App，60 秒内自动生效。

第 1 步：复制这段 SQL

create or replace function public.app_unread_total()
returns int
language sql
security definer
set search_path = public
as 'select (select count(*)::int from public.messages where is_read = false)
         + (select count(*)::int from public.chat_messages where is_read = false and role = ''visitor'')';

grant execute on function public.app_unread_total() to anon, authenticated;

select public.app_unread_total() as total_unread;
这段里没有 $ 符号，复制粘贴不会像上次那样被吃掉字符。

第 2 步：到 Supabase 执行

  1. 点下面的按钮打开 SQL 编辑器（已登录 Supabase 的话直接进）
  2. 把复制的 SQL 粘到输入框，点右下角 Run
  3. 成功标志：下面出现一行结果，total_unread = 2（或你当前实际未读数）
打开 Supabase SQL 编辑器 →

第 3 步：回 App 验证

  1. 打开「中天后台」→ 右上角 🔔 提醒自检
  2. 点 立即同步未读并写角标
  3. 看「原生角标写入」这一行：应该变成 已发角标通知 · 2 条
  4. 回桌面看图标：右上角应出现数字 2
如果「原生角标写入」显示失败原因，把那张截图发过来，那行字就是服务端返回的真实报错，一看就能定位。
