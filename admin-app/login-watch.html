谁在什么时候登录了你的后台

记录 + 微信当场提醒，安卓 / 苹果 / 电脑都一样生效。

配好之后，每一次登录都会留一条记录：时间、账号、设备型号、浏览器、IP、城市。

下面两种情况会当场推到你微信：① 第一次出现的 IP（换了手机或换了网络）② 密码输错。你自己平时在同一台手机上登录，只记录、不打扰。

第 3 步：验货

  1. 回到后台，点上面第 4 个页签 🔐 谁在用
  2. 应该能看到刚才这次登录（当前设备 + 当前 IP）
  3. 用另一台手机开流量登录一次 → 几秒内微信会弹「有人登录了你的后台」，并标注「第一次出现的 IP」
  4. 故意输错一次密码 → 微信弹「后台登录失败（密码错误）」
第一次一定是「新 IP」——因为表刚建、还没有历史记录。之后就只记新的了。

几个说明

  1. IP 是服务端取的，也就是 Supabase 看到的真实来源，不是浏览器自己报的，改不了
  2. 城市是尽力而为：查归属地要 2 秒，超时就只记 IP，不会卡住登录
  3. 记录保留 180 天，SQL 每次跑都会顺手清掉更早的
  4. 只有登录后的管理员能看这些记录，匿名访客读不到（行级权限已锁）
这个功能只能告诉你「有人从哪台设备、哪个网络登录过」，看不到对方屏幕和摄像头 —— 浏览器和手机系统都不允许，任何网站都做不到。真是账号被登，最有效的动作还是立刻改密码。
