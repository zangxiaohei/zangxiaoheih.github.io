开通「发图片 / 文件」

只用做一次，之后网站聊天和后台都能直接发图、发文件、发 PDF。

开通后：访客在聊天窗口点 🖼 发照片、点 📎 发文件，还能直接 Ctrl+V 粘贴截图；你在后台也能同样发图发文件，两边互相看得见。

图片会自动压缩到长边 1600px（手机拍的原图几 MB，传上去只剩两三百 KB），单个文件上限 10MB。

几点说明

  1. 图片和文件存在 Supabase 的存储里，不占数据库，也不会拖慢聊天
  2. 聊天记录里只存一个链接，所以老消息、新消息都能一起显示
  3. 免费额度 1GB，按压缩后 200KB 一张算，大约能存 5000 张；要清理就删 chat-files 桶里的文件
  4. 只能发，不能执行：图片在页面里显示，文件点一下下载，不会自动打开或运行
