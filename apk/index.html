中天后台 App（安卓）

装上后桌面图标会显示未读数字角标

下载安装包（约 150 KB）
版本 1.10 · 适用于安卓 8.0 及以上 · 覆盖安装即可，不用卸载

1.10 版改了什么

  • App 内直接更新，不用再手动下载：打开后台如果发现新版本，顶部会弹一条绿色提示，点「立即更新」→ 自动下载 → 自动弹安装界面 → 点「安装」就覆盖升级了。数据不丢、不用卸载
  • 第一次需要允许一次「安装未知应用」（系统会自己跳到那个开关页，点一下允许再回来即可）
  • 修「息屏收不到」：息屏期间保持 CPU 工作 + 看门狗换成 Doze 也能触发的闹钟
  • 修「开了声音震动却不响」：通知渠道换新，铃声和震动重新写入
  • 自检面板新增手机铃声模式、通知音量、勿扰、渠道铃声、渠道震动五项真实读数

不想开自启动？完全可以（看这里）

  • 只要 App 还在后台，消息照收：退到桌面后 10 秒内就会收到通知和角标，不需要自启动权限
  • 真正建议开的是「省电策略 → 无限制」：这个才是防止被系统休眠的关键，比自启动管用，也不用给自启动权限
  • 再加一个小动作：从屏幕底部上划打开最近任务，长按本应用卡片下拉锁定，系统清理时不会清它
  • 代价只有一个：手机关机重启后，或被你手动清理掉后，要自己打开一次 App，才会继续后台收

要弹出+响铃，这两个开关必须开

  1. 本应用通知设置：设置 → 通知管理 → 中天后台 → 打开「发声」「振动」「悬浮通知」「锁屏通知」
  2. 通知类别：同一个页面往下拉，点「新消息（弹窗提醒）」→ 重要度选「重要」，并允许发声/振动/横幅
  3. 自启动：设置 → 应用设置 → 应用管理 → 中天后台 → 自启动 → 打开
  4. 省电策略：同上页面 → 省电策略 → 无限制；最近任务里下拉锁定本应用
App 里的「🔔 提醒自检」现在会直接显示「自启动」「省电策略」的真实状态，还有一键跳转的按钮，不用自己翻菜单。

安装步骤

  1. 点上面的绿色按钮下载 APK 文件
  2. 下载完成后点开它，若提示"禁止安装未知来源应用"，点 设置 → 允许来自浏览器的安装，再返回继续
  3. 安装完成，打开「中天后台」，弹出通知权限时选 允许
  4. 用管理员邮箱登录一次，之后桌面图标就会显示未读数字

角标不显示？打开这两个开关

  1. 通知权限：设置 → 通知管理 → 中天后台 → 允许通知
  2. 桌面角标：设置 → 桌面（或桌面设置）→ 图标角标 → 找到「中天后台」→ 允许
  3. 后台运行：设置 → 应用管理 → 中天后台 → 省电策略 → 选「无限制」（否则息屏后可能停止刷新）
App 会常驻一条静音的未读提醒通知，这是安卓角标的工作方式，不是出错。
苹果手机不需要装这个包：用 Safari 打开后台 → 分享 → 添加到主屏幕，角标已经能正常显示。
