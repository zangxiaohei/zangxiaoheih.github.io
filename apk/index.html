中天后台 App（安卓）

装上后桌面图标会显示未读数字角标

下载安装包（147 KB）
版本 1.5 · 适用于安卓 8.0 及以上 · 覆盖安装即可，不用卸载

1.5 版改了什么

  • 角标改按安卓官方模型实现：独立「未读消息」通知驱动角标（之前那条是常驻服务通知，系统不认）
  • 换用全新通知渠道，旧的坏渠道会自动作废（通知渠道的角标开关创建后无法修改，必须换新的）
  • 「提醒自检」现在能读到手机真实状态：通知开关、角标渠道、原生写入结果，还带一键跳系统设置
  • 小米/华为/荣耀/vivo/三星额外走各自私有通道兜底

安装步骤

  1. 点上面的绿色按钮下载 APK 文件
  2. 下载完成后点开它，若提示"禁止安装未知来源应用"，点 设置 → 允许来自浏览器的安装，再返回继续
  3. 安装完成，打开「中天后台」，弹出通知权限时选 允许
  4. 用管理员邮箱登录一次，之后桌面图标就会显示未读数字

角标不显示？打开这两个开关

  1. 通知权限：设置 → 通知管理 → 中天后台 → 允许通知
  2. 桌面角标：设置 → 桌面（或桌面设置）→ 图标角标 → 找到「中天后台」→ 允许
  3. 后台运行：设置 → 应用管理 → 中天后台 → 省电策略 → 选「无限制」（否则息屏后可能停止刷新）
App 会常驻一条静音的未读提醒通知，这是安卓角标的工作方式，不是出错。
苹果手机不需要装这个包：用 Safari 打开后台 → 分享 → 添加到主屏幕，角标已经能正常显示。
